# OMR with instrument names

This repository holds the scores and task records of a campaign on [Let's Encode](http://localhost:5199/), where volunteers encode music together.

To take part, please use the [campaign page](http://localhost:5199/test-20261021-1). Please don't edit files or open pull requests here directly: the campaign's automation keeps the scores and task records consistent, and it can only do that for work done through the campaign page.
